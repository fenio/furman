# Keyboard Shortcuts

Complete keyboard shortcut reference for Furman. On Linux, replace Cmd with Ctrl.

## Navigation

| Shortcut | Action |
|----------|--------|
| Arrow keys | Move cursor |
| Home / End | Jump to first / last entry |
| Page Up / Down | Scroll by page |
| Enter | Open file or enter directory |
| Backspace | Go to parent directory |
| Tab | Switch active panel |
| Space | Toggle select and move down |

## Selection

| Shortcut | Action |
|----------|--------|
| Shift + Arrow | Extend selection |
| Shift + Home / End | Select to start / end |
| Insert | Toggle select and move down |
| Type any letter | Quick filter |
| Esc | Clear filter |

## File Operations

| Shortcut | F-key | Action |
|----------|-------|--------|
| Cmd+R | F2 | Rename (single file) or batch rename (multiple) |
| Cmd+3 | F3 | View file |
| Cmd+E | F4 | Edit file |
| Cmd+C | F5 | Copy to other panel |
| Cmd+M | F6 | Move to other panel |
| Cmd+N | F7 | Create directory |
| Cmd+Backspace | F8 | Delete |
| Cmd+Z | — | Undo last operation (delete/rename) |
| Cmd+I | F9 | Properties |
| Cmd+Q | F10 | Quit |

## Tabs

| Shortcut | Action |
|----------|--------|
| Cmd+Alt+T | New tab in active panel |
| Cmd+Alt+W | Close current tab |

## Panels & Layout

| Shortcut | Action |
|----------|--------|
| Cmd+P | Toggle single / dual pane |
| Cmd+B | Toggle sidebar |
| Cmd+D | Save workspace |
| Cmd+J | Toggle transfer panel |
| Cmd+Y | Sync directories |
| Cmd+Shift+D | Compare directories |
| Cmd+Shift+L | Toggle dark / light theme |

## Terminal

| Shortcut | Action |
|----------|--------|
| Cmd+T | Bottom terminal |
| Cmd+Shift+T | In-pane terminal |
| Cmd+\` | Quake console |
| Esc | Hide quake console |

## Search

| Shortcut | Action |
|----------|--------|
| Cmd+F | Search files |
| Cmd+Shift+P | Command palette |
| Cmd+/ | Keyboard shortcuts cheatsheet |

## Connections

| Shortcut | Action |
|----------|--------|
| Cmd+S | Connection Manager / disconnect |
| Cmd+D | Bookmark S3 or SFTP path (save workspace when local) |
| Cmd+I | Properties / connection info |
| Cmd+Y | Sync between panels |

## S3

| Shortcut | Action |
|----------|--------|
| Cmd+U | Presigned URL to clipboard |
| Cmd+K | Copy S3 URI to clipboard |
| Cmd+L | Bulk storage class change |
| Cmd+Shift+I | Bucket properties |

## Context Menu

Right-click any file or folder to access common operations (Open, View, Edit, Copy, Move, Rename, Delete, New Folder, Properties) without memorizing shortcuts. Right-click empty space for a reduced menu (New Folder, Properties).

In S3 panels, the context menu includes additional items: Presign URL, Copy S3 URI, and Bulk Storage Class.
