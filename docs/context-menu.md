# Context Menu

Right-click any file or folder to access common operations without memorizing keyboard shortcuts.

## File & Folder Menu

Right-click a file or folder to see:

| Item | Shortcut | Notes |
|------|----------|-------|
| Open | Enter | Disabled on directories |
| View | F3 | Disabled on directories |
| Edit | F4 | Disabled on directories |
| Copy | F5 | Copy to other panel |
| Move | F6 | Move to other panel |
| Rename | F2 | Disabled on `..` |
| Delete | F8 | Disabled on `..` |
| New Folder | F7 | |
| Properties | F9 | |

## Empty Space Menu

Right-click empty space below the file list to see a reduced menu:

- **New Folder** (F7)
- **Properties** (F9) — shows properties for the current directory

## S3 Panels

When browsing an S3 connection, additional items appear at the bottom of the context menu:

- **Presign URL** — generate a presigned URL and copy to clipboard
- **Copy S3 URI** — copy the `s3://bucket/key` URI to clipboard
- **Bulk Storage Class** — change storage class for selected objects

## Dismissing

Click anywhere outside the menu, or press **Esc** to close it.
