# Command Palette

Press **Cmd+Shift+P** (macOS) or **Ctrl+Shift+P** (Linux) to open the command palette.

## Usage

- Type to filter commands by name
- Arrow keys to navigate, Enter to execute, Escape to close
- Commands are organized by category: File, Navigation, Panel, Terminal, Connection, S3, Search, Display
- S3/SFTP-specific commands are hidden when the active panel is not using that backend
- Each command shows its keyboard shortcut on the right

## Categories

| Category   | Examples                                         |
|------------|--------------------------------------------------|
| File       | Rename, Copy, Move, Delete, Create directory     |
| Navigation | Go to parent, Switch panel, Jump to first/last   |
| Panel      | Toggle layout, Toggle sidebar, Sync directories  |
| Terminal   | Bottom terminal, In-pane terminal, Quake console |
| Connection | Connect/Disconnect, Connection Manager           |
| S3         | Presigned URL, Copy S3 URI, Bulk storage class   |
| Search     | Search files                                     |
| Display    | Toggle theme, Preferences, Keyboard shortcuts    |
