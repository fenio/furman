# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
**[Security → Report a vulnerability](https://github.com/fenio/furman/security/advisories/new)**.

Do not open public issues, pull requests or discussions for security problems.

Include the affected version, steps to reproduce and the impact you expect.
You will get a reply in the advisory thread, and fixes are coordinated there
before anything is disclosed publicly.
